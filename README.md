# Bonely Store

Loja em HTML, CSS e JS puros, sem build. Abra `index.html` no navegador.

## Estrutura
- `index.html`: página base
- `style.css`: estilos
- `app.js`: loja, área do cliente, painel administrativo e dados
- `privacidade.html` e `cancelamento.html`: políticas (editáveis, abrem em página própria)
- `IMGs/`: imagens (logo em `IMGs/logo_img.jpeg`)

## Contatos
No topo de `app.js`: `WA`, `PHONE` e `IG`. Nas políticas, o contato está no rodapé de cada arquivo.
